# Security Policy

This SDK strictly supports the **Pesapal V3 API**. Earlier versions of the Pesapal API are not supported.

## Supported Versions

Currently, the following versions of the Pesapal Node.js SDK are supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

If you find a security vulnerability or any security-related issue, please let us know immediately so we can address it.

To report a vulnerability:
1.  **Create a GitHub Issue:** Open a new issue in this repository.
2.  **Tag as Security:** Use a descriptive title and label the issue as "security" if possible.
3.  **Provide Details:** Include a detailed description of the vulnerability, steps to reproduce, and the potential impact.

We take security seriously and will prioritize triaging and fixing reported vulnerabilities. Thank you for helping keep this project safe for everyone!
